About

The CLAID framework

CLAID joins community detection, anomaly detection and influential-user identification into a single workflow. Social networks are dense webs of connections: not every participant is genuine, and inside every community a few users shape the group's dynamics. CLAID finds the communities, isolates the suspicious nodes and names the influencer of each healthy community.

Dataset (§4.3)

Dataset(1).csv (5,029 rows) is the layout described in the report: SOURCE_SUBREDDIT, TARGET_SUBREDDIT, POST_ID, TIMESTAMP, ADDRESS, FOLLOWERS, PHONE NO, LIKES, COMMENTS, LINK_SENTIMENT and an 86 value PROPERTIES vector. The smaller Dataset.csv in the same zip is supported too (--dataset). Rows whose endpoints are missing (the literal NaN) and self loops are dropped, and the dashboard reports how many.

How the figures are produced

  • Networks larger than 400 nodes are drawn as the largest component, trimmed to the best-connected nodes so the picture stays readable; the figure caption says so.
  • Exact Brandes betweenness is O(n·m), so the graph-wide ranking switches to a sampled estimate above 800 nodes. The §4.7 per-community scores stay exact.
  • Girvan-Newman is O(n·m²), so the §4.5 comparison runs it on a 90 node subgraph, stated in the table note.
  • All figures share one theme and palette (src/claid/plots.py) with the stylesheet, so a run reads as a single report.

How the evaluation is scored

The dataset ships no ground-truth labels, so the notebook's own F1 = 1.000 was self-referential - it compared a label set with itself. Here every row names the reference method it is scored against, and label-free measures (modularity, ARI, NMI) are reported next to precision, recall and F1.

How to run everything

python tools/export_notebook.py            # notebook     ->  exploratory/*.py
python exploratory/claid_workflow.py       # the study pipeline (12 figures)
python run_claid.py --source bestof        # framework from the command line
python app.py                              # this web application
python tools/smoke_test.py                 # end-to-end checks (framework + every route)

run_claid.py, app.py and the smoke test put src on the import path themselves, so they work in a fresh clone. Only the module form python -m claid.cli needs PYTHONPATH (set PYTHONPATH=src on Windows, export PYTHONPATH=src elsewhere). A full run takes about half a minute and prints every stage as it goes; a repeat run in the same process is served from the cache.

Configuration and secrets

No key, token or password is stored in this repository. The application reads its configuration from the environment, or from a git-ignored .env file (cp .env.example .env):

variablemeaningdefault
CLAID_SECRET_KEY signs session cookies random per process{% if not secret_from_env %} - currently unset{% else %} - set{% endif %}
CLAID_HOSTinterface to bind127.0.0.1
CLAID_PORTport to bind5000
CLAID_DEBUGFlask debugger, local use onlyoff

Generate a key with python -c "import secrets; print(secrets.token_hex(32))". Responses carry a self-only content-security policy, X-Frame-Options: DENY and X-Content-Type-Options: nosniff, and request bodies are capped at 64 KB. Nothing is loaded from a third-party CDN - the charts on a results page are figures rendered by the framework and the rankings use plain CSS bars.
