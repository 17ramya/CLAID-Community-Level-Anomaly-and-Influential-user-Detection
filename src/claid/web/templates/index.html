Social-network analysis framework

Community, anomaly and influencer detection in one pass

CLAID reads a social-interaction graph and answers three questions together: which communities exist (§4.5, Louvain modularity), which nodes are anomalous (§4.6, Isolation Forest) and who influences each healthy community (§4.7, betweenness centrality). Everything is scored with precision, recall and F1 (§5.2.5) and exported as JSON, CSV and figures.
