About the CLAID framework

CLAID integrates community detection, anomaly detection and influential-user identification into a single workflow. Social networks are dense webs of connections: not every participant is genuine, and inside every community a few users shape the group's dynamics. CLAID finds the communities, isolates the suspicious nodes, and names the influencer of each healthy community.

Dataset (§4.3)

Dataset(1).csv (5,029 rows) is the layout described in the report: SOURCE_SUBREDDIT, TARGET_SUBREDDIT, POST_ID, TIMESTAMP, ADDRESS, FOLLOWERS, PHONE NO, LIKES, COMMENTS, LINK_SENTIMENT and an 86 value PROPERTIES vector. The smaller Dataset.csv in the same zip is also supported (--dataset). Rows with a missing endpoint (the literal NaN) and self loops are dropped and reported on the dashboard.

How the figures are produced

  • Networks with more than 400 nodes are drawn as the largest component, trimmed to the best connected nodes so the picture stays readable.
  • Exact Brandes betweenness is O(n·m); the graph-wide ranking switches to a 200 source estimate above 800 nodes, while the §4.7 per-community scores are always exact.
  • Girvan-Newman is O(n·m²), so the §4.5 comparison runs it on a 90 node subgraph (stated in the table note).

How to run everything

python tools/convert_notebook.py          # .ipynb  ->  notebook_to_py/*.py
python notebook_to_py/CLAID_notebook.py   # execute the converted notebook
python -m claid.cli --source bestof       # framework from the command line
python app.py                             # this web application
curl "http://127.0.0.1:5000/api/claid?source=bestof"   # JSON API

Run the last two from the repository root with src on PYTHONPATH (set PYTHONPATH=src on Windows, export PYTHONPATH=src elsewhere) — on Windows python app.py sets it automatically.
