Run the CLAID framework

One pass over the social-interaction dataset performs three linked analyses (python app.py serves this page locally): communities are found with Louvain modularity (§4.5), anomalies with an Isolation Forest (§4.6), and the most influential user of every healthy community is picked with betweenness centrality (§4.7). Results are scored with precision, recall and F1 (§5.2.5).

What each module reports

1. Community detection

§4.5 Louvain modularity, benchmarked against greedy modularity, label propagation and Girvan-Newman (§5.2.1, figure 14).

2. Anomaly detection

§4.6 Isolation Forest over node and community features, compared with the degree-centrality rule of figure 8 (§5.2.2, figure 15).

3. Influential users

§4.7 betweenness centrality inside every non-anomalous community, compared with closeness and degree centrality (§5.2.3, figure 16).

4. Framework view

§5.2.4 lists the communities interacting with the chosen source node together with their anomalies and influencers.
